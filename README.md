# Philippine Constitution Civic Guide

A responsive, one-page educational portfolio project about the **1987 Constitution of the Philippines**. It uses plain HTML, CSS, and JavaScript—no framework, build system, or backend is required.

## Open locally

Open `index.html` in any modern web browser.

For local development with a server, you can use the VS Code Live Server extension or another static-file server.

## Project structure

```text
philippine-1987-constitution-site/
├── index.html        # Semantic page content and structure
├── css/
│   └── styles.css    # Responsive visual design and print styles
├── js/
│   └── main.js       # Mobile menu, article search, and quiz behavior
└── README.md
```

## Features

- Mobile-friendly, accessible navigation
- Plain-language guide to all 18 constitutional articles
- Article search/filtering
- Bill of Rights and branches-of-government highlights
- Four-question client-side knowledge check
- Keyboard focus states, skip link, reduced-motion support, and print styles

## Content note

This is an introductory civic-learning project. It is **not legal advice** and does not replace the official constitutional text. Before publishing, review all summaries against authoritative material.
